# AGENTS.md

AI agents working in this repo must follow these rules.

## Do not make decisions

A decision is any choice that may lead to work that needs to be undone. When faced with a decision, stop and ask. You may propose options but you may not choose one on your own.

## Be minimalistic

- Implement only what you are instructed to do and make no other changes.
- Be direct and precise in interactions, rather than wordy.
- Report changes as summarized list when possible.

## Tests

Only write tests when explicitly instructed to do so.

## No comments

Do not add comments to the code when you make changes.

## Verification of changes

Only verify changes when explicitly asked.
